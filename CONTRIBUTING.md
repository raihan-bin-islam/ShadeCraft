# Contributing to ShadeCraft

Thank you for your interest in contributing! Your help makes ShadeCraft better for everyone.

## How to Contribute

### Reporting Issues

If you find a bug or have a feature request, please open an issue in this repository.  
Try to include a clear description, steps to reproduce, and any relevant screenshots or logs.

### Submitting Pull Requests

1. **Fork** the repository and clone your fork locally.
2. Create a new branch for your change:
   ```bash
   git checkout -b my-feature-branch
   ```
3. Make your changes with clear, focused commits.
4. Run tests and verify your changes do not break existing functionality.
5. Push your branch to your fork:

```bash
   git push origin my-feature-branch
```

6. Open a Pull Request against the `main` branch of this repo.

### Code Style & Guidelines

- Use TypeScript (where applicable) and follow existing coding patterns.
- Format your code with Prettier and follow ESLint rules (if set up).
- Write clear, concise commit messages describing your changes.

### Development Setup

See the [README](#readme) for instructions on how to set up the project locally.

### Need Help?

If you’re unsure how to proceed or want feedback on your idea, feel free to open a discussion or issue first!

Thanks again for helping improve ShadeCraft! Every contribution counts.
